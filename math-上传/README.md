# 数学破题训练

把数学的「灵光一现」拆成可以反复训练的东西：**看题 → 强制先想 10 秒 → 只看第一步怎么动**。

不是刷题软件，也不是错题本。它训练的是**模式识别**：这道题一露头，你能不能立刻判断「该往哪个方向动第一下」。

## 为什么这么做

数学卡住的时候，卡的不是计算，是**认不出这是哪一类题**。而「认出类型 → 选出第一招」这件事本质是**检索**，和背单词同构，所以能用间隔重复 + 交错练习来练。

练不到的：计算熟练度、完整书写、临场检查。那些还得在纸上做。**这个 App 只是把"想到"这一段单独拎出来高强度重复。**

## 怎么用（关键，照做才有效）

1. **只加你真正卡住的题**——不是所有错题，是「看了答案才恍然大悟」的那种
2. 每题只填两样必填：
   - **破题动作**：第一步做什么，一句话。写"分离参数"，不要写整道题的解法
   - **线索**：题面上什么信号让你想到它（"看到恒成立 + 参数在分母"）
   - 为什么这么想（可选）：解释给自己听
3. **同模式的题放同一组**（保存时选"属于哪一组"），系统会把同组的变式分开出，不会连着考你同一招
4. 每天 10–15 道，别贪多
5. 评分老实点：**没头绪 / 想到方向 / 秒出第一步**

两周后看一个指标：**同一模式、没见过的题面，你能否 10 秒内说出第一步？**
涨了 → 加内容；没涨 → 这套迁移对你不成立，别硬撑。

## 三个必须守住的设计

| 机制 | 为什么不能删 |
|---|---|
| **思考倒计时 10 秒** | 没有它，你会立刻翻答案，那就退化成"看答案"，一点用没有 |
| **只练第一步** | 一旦写完整解法，单张卡的负担变成 5 分钟，你坚持不了三天 |
| **同组变式交错出** | 连着出同模式的题，你会「顺着套路做」；考试一混就崩，这才是真难点 |

倒计时秒数、每日新题上限、重学间隔都在设置里可调。

## 本地跑

```bash
node tools/serve.mjs      # 默认 http://127.0.0.1:8787，若被占用用 PORT=8798 node tools/serve.mjs
```

## 部署到手机

和文言文那套完全一样：新建一个 GitHub 仓库 → 把本目录**里面的内容**传到仓库根 → Settings → Pages → main /(root) → Save → 手机打开网址 → 添加到主屏幕。

## 数据

- 全部存在手机浏览器本地（IndexedDB），不上传
- **题面是图片，会让备份文件很大**，但换手机必须靠它：设置 → 导出 JSON
- 图片在保存时会自动压到长边 1200px 的 JPEG（约 100–200KB/张）

## 文件

```
index.html   页面骨架
app.js       逻辑：拍照压缩入库、倒计时门禁、交错队列、评分
srs.js       间隔算法（和文言文版同一套）
db.js        IndexedDB（库名 math-pattern-srs，和文言文版互不干扰）
styles.css   样式
sw.js        离线缓存
tools/serve.mjs 本地预览
```
